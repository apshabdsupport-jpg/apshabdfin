## Generation method

Created with the built-in image-generation edit workflow. The prompt set locked each subject's identity, pose, hands, props, background, lighting, crop and non-shirt clothing while replacing only the visible upper garment. Shirt colors, front/back orientation, city typography, detailed artwork, cotton texture, seams, folds, occlusion and contact shadows were specified per image.

The Bangalore shirts use the project's official BLR / 04 identity, Kannada city typography and APSHABD wordmark because the Bangalore product page still contains image placeholders rather than finished garment photography.
