## Final prompt set

The built-in image-editing workflow used one prompt per source image. Each wardrobe prompt treated the source as an identity-preserving edit target, treated the selected product mockup as the exact garment reference, and required the referenced colorway, location lettering, regional script, front/back orientation, print layout, cotton texture, seams, folds, perspective, occlusion, lighting and shadows. Faces, bodies, poses, accessories, lower garments, scenery, framing and aspect ratios were locked as invariants. Image 5 used a text-localization prompt that preserved the red-hand photograph, removed the old copy, retained its yellow editorial-serif style, and embedded the approved APSHABD wordmark once in the exact sentence. The revised image-5 prompt rebuilt the composition at an exact 3:4 ratio with an optically centered three-line hierarchy and the ending `in India`.
