# Recreated city-tee campaign assets

High-fidelity clothing edits based on the ten supplied campaign references and the APSHABD product artwork in this project. Numbered files correspond to the supplied source images.

## Assignment

1. Delhi — Connaught Place / stadium product scene
2. Mumbai Bandra + Delhi Connaught Place / blurred launch teaser
3. Chennai Mylapore / chalk-outline back print
4. Mumbai Dadar / safe studio portrait adaptation
5. Chennai Adyar + Delhi Hauz Khas / two-model editorial
6. Bangalore BLR / 04 / coastal portrait
7. Chennai T. Nagar / pink auto-rickshaw editorial
8. Mumbai Andheri + Dadar / snack-stall scene
9. Chennai Anna Nagar + Delhi Chandni Chowk + Mumbai Colaba / coast scene
10. Delhi Connaught Place front and back / truck scene

## Generation method

Created with the built-in image-generation edit workflow. The shared prompt set locked the original identity, pose, framing, environment, lighting, props and lower garments while replacing only upper garments with the referenced city T-shirts. Product typography, colors, front/back orientation, cotton texture, seams, folds, occlusion and contact shadows were explicitly preserved.

Image 4's exact source staging was rejected by the image safety filter. Its delivered version is a safe waist-up portrait that preserves the model, glasses, hair, warm curtain lighting and Dadar garment while omitting the blocked foreground element.
