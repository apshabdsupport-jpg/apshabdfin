# Free tools and authoritative resources

## Generate and refine

- Google Flow: https://labs.google/fx/tools/flow
  - Current free listing includes daily Flow credits, Gemini Omni Flash, reference/image-to-video tools and video editing. Availability can vary by region.
- Gemini Omni Flash documentation: https://ai.google.dev/gemini-api/docs/omni
  - Authoritative reference for image/reference-to-video, aspect ratio, stateful editing, single-shot prompting and current limitations.
- Gemini Apps video help: https://support.google.com/gemini/answer/16126339
  - UI workflow and supported reference uploads.
- Veo 3.1 documentation: https://ai.google.dev/gemini-api/docs/video
  - Optional fallback when true first/last-frame control is needed; Veo supports frame-specific generation where Omni currently does not.

## Prepare precise map references

- QGIS: https://qgis.org/project/overview/
  - Free desktop GIS for opening the included shapefile archive, filtering roads/rail and exporting SVG/PNG.
- Mapshaper: https://mapshaper.org/
  - Free browser/CLI utility for converting the included shapefile to GeoJSON and simplifying geometry.
- Mapshaper simplification guide: https://mapshaper.org/docs/guides/simplification.html
- geoBoundaries API: https://www.geoboundaries.org/api.html
- BBBike Bombay extract: https://download.bbbike.org/osm/bbbike/Bombay/
- OpenStreetMap licence and attribution: https://www.openstreetmap.org/copyright

## Compress the final website video

- HandBrake: https://handbrake.fr/downloads.php
  - Free local GUI transcoder; no account required.
- FFmpeg: https://www.ffmpeg.org/download.html
  - Free command-line transcoder for MP4/WebM conversion, resizing and audio removal.

## Deliberately excluded

- Paid GEOlayers, Mapbox and Adobe subscriptions are not required for this pack.
- Google Earth imagery is not used because it requires visible attribution and is unnecessary for the flat map treatment.
- Random text-to-video generation is not the recommended starting point because it cannot preserve the supplied geography reliably.
